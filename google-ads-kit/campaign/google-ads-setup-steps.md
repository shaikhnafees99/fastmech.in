# Google Ads Setup Steps

1. Create a Search campaign.
2. Choose goal: Leads or Phone calls.
3. Final URL: https://fastmech.in/
4. Locations: Mumbai, Andheri, Thane, Vashi.
5. Add call asset: +91 70218 10153.
6. Import or copy keywords from google-ads-keywords.csv.
7. Add negative keywords from google-ads-negative-keywords.txt.
8. Use responsive-search-ads.csv for headlines/descriptions.
9. Add sitelinks and callouts from call-assets-and-sitelinks.md.
10. Start with INR 300-500 per day and monitor search terms daily.

Do not use broad match heavily at launch. Start with phrase/exact style intent keywords.
